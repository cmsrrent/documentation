# Documentation

This repository is a personal collection of study notes and reference material for software testing, automation, and web development topics.

## Contents

- `Gherkin.md` — key Gherkin syntax and BDD testing concepts
- `Accessibility.txt` — accessibility testing notes
- `Cypress.txt` — notes on Cypress automation
- `appium.txt` — Appium mobile testing references
- `k6.txt` — performance testing with k6
- `lambda.txt` — Lambda-related notes
- `Git commands.txt` — commonly used Git commands
- `Javascript.txt` — JavaScript notes and references

## Purpose

The project serves as a quick-reference vault for learning and revisiting technical concepts related to:

- Behavior-driven development (BDD)
- Test automation frameworks
- Accessibility and quality assurance
- Performance testing
- JavaScript and tooling basics
- Git workflow commands

## Notes

This is a documentation-focused repository, so it is intended for reading and study rather than running application code.
